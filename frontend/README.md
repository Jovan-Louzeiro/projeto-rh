# RH Digital — Frontend

Frontend do sistema de RH municipal, recriado em React + TypeScript + Vite, mantendo o design do protótipo.

## Tecnologias
- React
- TypeScript
- Vite
- Flaticon UIcons 4.0.0
- CSS responsivo

## Instalação

Requer Node.js instalado.

```bash
npm install
npm run dev
```

Abra o endereço mostrado pelo Vite, normalmente:
http://localhost:5173

## Build de produção

```bash
npm run build
npm run preview
```

## Login do protótipo

O formulário aceita qualquer e-mail/senha válidos no navegador. Os valores iniciais são:
- E-mail: rh@carutapera.ma.gov.br
- Senha: 123456

Este frontend ainda usa dados fictícios locais. Não é um sistema de autenticação real.
